# Data Dictionary

| Column | Meaning |
|---|---|
| order_id | Unique order identifier |
| order_date | Date of order |
| city | Customer/order city |
| age_group | Respondent age band |
| food_category | Ordered food category |
| platform | Ordering channel |
| order_time | Daypart of order |
| order_amount | Order total in INR |
| payment_method | Payment type |
| delivery_minutes | Delivery duration in minutes |
| rating | Customer rating from 1 to 5 |
| orders_per_month | Self-reported/illustrative monthly order frequency |

**Important:** The supplied rows are synthetic and randomly generated for software demonstration.
